Spaceman Perps is an offline simulation for learning perpetual-futures mechanics — isolated margin, leverage, funding, and liquidation — using play money only. No real funds, exchange, or order book are involved.

The name you enter is just a local label — it keeps separate paper accounts for people sharing one browser, with no password and no data leaving this device. It doesn't sync across other browsers or devices: the same name on a different computer starts a fresh account there.

The ADA/USD anchor price is real: where this page can reach a public price source directly, it refreshes about once a minute; where it can't (like this hosted preview), it falls back to a periodic snapshot anchor instead. Between refreshes, the displayed price does small simulated wiggles bounded tightly around that real anchor (clearly separate from it) so the chart doesn't sit frozen — it is not a tick-by-tick live feed. This isn't literally sourced through Charli3's oracle API (that requires a developer API key), though Charli3's own on-chain ADA/USD feed tracks the same underlying market price. Mechanics are loosely modeled on how live products such as Ascend Market and Strike Finance describe leveraged perpetuals, for educational purposes only — not investment advice.

The 1D and 1W chart views start out flat because there's no fabricated week of history behind them — they fill in with real variation as the hourly anchor keeps refreshing over time.
